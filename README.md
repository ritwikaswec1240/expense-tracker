
💰 Expense Tracker
A simple, fast, and responsive web application designed to help users effectively manage their personal finances by tracking income and expenses. Built using core web technologies, this tracker provides a clean interface for adding, editing, deleting, and filtering financial records.

🚀 Live Demo
You can interact with the live application here:

https://ritwikaswec1240.github.io/expense-tracker/

✨ Features
Add Expenses: Quickly log new expenses with a name, amount, category, and date.

CRUD Operations: Full functionality to Create, Read, Update (Edit), and Delete expense records.

Expense Summary: Calculates and displays the total amount spent.

Filtering: Filter expenses instantly based on different categories (Food, Transport, Entertainment, Other).

Simple UI: Clean and intuitive design for easy daily use.

💻 Technologies Used
This project is a static web application built entirely with front-end technologies:

HTML5: For the core structure and content.

CSS3: For styling and visual presentation.

JavaScript (Vanilla JS): For all application logic, including form handling, DOM manipulation, and data management.

🛠️ Installation and Setup
This is a client-side application and does not require any backend or external server to run.

Clone the Repository:

Bash

git clone https://github.com/ritwikaswec1240/expense-tracker.git
Open the File: Navigate to the project directory and simply double-click the index.html file to open the application in your default web browser.
